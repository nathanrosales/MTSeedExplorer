# MTSeedExplorer

"QOL" mod that skips the hassle of repeatedly restarting runs until you get a good starting draft. This mod simulates dozens or hundreds of normal game starts and lets you choose which one to move forward with. Creates "real" shareable runs.

## Installation
Copy the mod contents to the 'BepInEx/plugins' folder of your Monster Train 2 installation directory.
